# Riverside transcripts

Drop the transcript exports from Riverside here — one file per episode.

There's no Riverside API access from the agent environment, so transcripts
have to be exported manually (or in bulk) from riverside.fm: open each
recording → Transcript → download (TXT preferred; SRT also fine, the
timestamps in SRT are actually useful for building the timestamp lists in
show notes).

Naming convention — please keep it sortable and matchable:

```
transcripts/ep001-guest-name-or-topic.txt
transcripts/ep002-....txt
```

If the Riverside export names don't include the episode number, keep the
original filename but add the episode number as a prefix. When in doubt,
any consistent scheme works — the matching step in the workflow can handle
date- or guest-based matching, it's just slower.
